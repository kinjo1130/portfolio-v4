勤怠・シフト管理システムの構築の全般を担当しました。実装だけでなく、顧客との打ち合わせや対応状況の報告書作成まで受け持ちました。

## やったこと

- **シフト管理の中核機能**
  - 募集期間ベースのシフト希望提出・自動割当・一括確定のフロー
  - 勤務調整マトリクスUI（セルクリックで編集、基準月期間表示、週送り）
  - 自動割振で弾かれた希望とその理由の表示
- **マスタ管理・データ連携**
  - 企業・エリア・店舗マスタのCRUD
  - CSV取込・エクスポート（推奨メンバー・店舗・POS売上）
- **品質・運用**
  - CI（lint・型チェック）とテストの整備、JWT認証、CD失敗対策
  - クライアントフィードバックへの継続対応と「対応状況ご報告書」の作成

## 使った技術

- Laravel (PHP)
- React + Vite / TypeScript / Tailwind CSS
- PostgreSQL
- XServer
