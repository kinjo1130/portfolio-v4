セキュリティレビューAIのPoCから始まり、セキュリティアセスメント・教育プラットフォームの開発と、別クライアント向けの推し活ロイヤリティプラットフォームの構築を担当しました。

## やったこと

- **セキュリティアセスメント・教育プラットフォームの開発**
  - フロントエンド（Next.js）を中心に、アセスメント画面・教育コンテンツ画面・マインドマップUIなどを実装
  - バックエンド（Express + Prisma）の管理画面向けアセスメント機能・教育フロー・リソース監視
  - RAGサービス（FastAPI + Celery + Azure OpenAI + Cosmos DB）とアプリ側の繋ぎ込み、Celery Workerのリソース監視
- **推し活ロイヤリティプラットフォームの構築**
  - Wixで運用されていたチケット販売とグッズ受注を自社システムへ移行するプロジェクトに、設計から入った
  - DB設計、認証（Better Auth + LINE Login）、バックエンドAPI（Hono）、フロントエンド（React + Vite）まで一人で通して実装
  - Terraform + Cloud Run のインフラ構築と GitHub Actions の CI/CD 整備

## 使った技術

- Next.js / React / TypeScript
- Node.js (Express / Hono) / Prisma / PostgreSQL
- Python / FastAPI / Celery / Azure OpenAI
- Azure Container Apps / GCP Cloud Run / Terraform
- Stripe / Better Auth / Supabase
