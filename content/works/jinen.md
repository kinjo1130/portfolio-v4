コミュニティ設計を支援するSaaSの開発に参加しました。コミュニティの設計書、KPI、ペルソナ（参加者像）、メンバーインタビューといった要素を一つのツールで管理するプロダクトです。バックエンドはLaravelのAPI、フロントはReact + Viteの構成で、KPIまわりを中心にほぼ全部の画面を触りました。コミット数はリポジトリで一番多いです。

## KPI機能

このプロダクトの中で一番作り込んだ領域です。

- KPI設計フロー（設計書ダッシュボード）のコンポーネントとルーティングを実装
- KPIカードのクリックからの遷移ロジック、並び替え、指標の更新とマイグレーション
- ダッシュボードのグラフは、値に応じてY軸の上限と目盛りステップを動的に計算するようにした。固定軸だと小さいコミュニティのKPIが張り付いて見えなくなるため

## 設計書・ダッシュボード

- 設計書詳細画面の遷移ロジックとステータスアイコン、コミュニティ情報（タイプ・開始日）のコンポーネント
- ステータス管理機能: seederでの初期データ、各ページからのステータス更新API連携
- 共通言語やバリュープロポジションの分類フィールド、改行の反映など、テキスト中心のドメインならではの細かい対応

## 認証・組織設定

- JWTの有効期限まわりの調整（12時間固定、型キャストの修正）と組織向け認証フック
- 組織ロゴのアップロード。パスの持ち方をAPIエンドポイントでURL生成する形に改善し、multipart/form-dataに対応

## その他

- DBのstring→text型変更（文字数制限の緩和）などのマイグレーション、不正JSONレスポンスのエラーハンドリング
- コーポレートサイト（Next.js）の軽微な改修

## 使った技術

- Laravel (PHP) / MySQL / Swagger
- React + Vite / TypeScript
- Next.js（コーポレートサイト）
