コミュニティ設計を支援するSaaS（設計書やKPI、ペルソナを管理するツール）の開発に参加しました。KPIまわりを中心にほぼ全部の画面を触っていて、コミット数はリポジトリで一番多いです。

## やったこと

- **KPI機能**
  - KPI設計フロー（設計書ダッシュボード）の実装、KPIカードの遷移・並び替え、グラフのY軸上限・目盛りの動的計算
- **設計書・ダッシュボード**
  - 設計書詳細画面の遷移ロジック、コミュニティ情報コンポーネント、ステータス管理機能
- **認証・組織設定**
  - JWT認証の調整、組織向け認証フック、組織ロゴのアップロード（multipart対応）
- DBマイグレーション・バリデーション整備、コーポレートサイトの軽微な改修

## 使った技術

- Laravel (PHP) / MySQL
- React + Vite / TypeScript
- Next.js（コーポレートサイト）
