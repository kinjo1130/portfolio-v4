採用プラットフォーム「youlish」の開発に参加しています。運営管理者、企業、求職者の3ロールを持つ採用SaaSで、担当が多いのはAI面接まわりですが、課金やTerraformまで必要なところは全部触ります。気づいたらコミット数はリポジトリで一番多くなっていました。

## AI面接機能

このプロダクトの中核です。求職者が非同期でAI面接を受け、企業が結果を見る、という流れの全体に手を入れています。

- **音声まわり**: TTS（音声合成）を実物のTTSに置き換え、停止操作やデフォルトピッチの調整に対応。文字起こしは質問の文脈を渡すことと音声の前処理で精度を上げ、STT失敗は構造化ログにして追えるようにした
- **同意と通知**: 規約同意モーダルを必須と任意の2段構成にし、非同期面接では個別同意に対応。面接完了時は求職者と企業の両方にHTMLメールで通知
- **共有**: AI面接の結果を外部共有リンクで社外に見せられるようにした
- 面接からの候補者同時会員登録、面接後アンケート（回答一覧つき）、面接官画像のアップロードなど周辺も一式

## 求職者・企業向け機能

- Googleログインの追加、メール認証画面の改善、認証フォームの一括クリア
- 求人票のフィルタ機能と掲載数集計。住所から都道府県を抽出して地域ミスマッチを抑える処理
- 動画フィードの改善: トリミングスライダーのタッチ操作対応、サムネイル表示崩れの修正、PR動画の任意化
- 企業向けの課金プラン機能と、管理画面の利用枠設定UI
- A8.netのアフィリエイト成果通知（Cookie管理）、Meta広告向けのGTM導入

## インフラとコード品質

- Terraformで本番環境を管理。放置されていたdriftの解消、production用のplan/apply workflow、Artifact RegistryのクリーンアップポリシーのIaC化、Secret Manager管理、レイテンシアラートの閾値調整
- コード規約をbackend / frontend / infraの3層で導入し、ESLintで規約違反を機械検知する形にした。any型禁止のガイドライン、型エラーの解消とCI型チェックの復帰、Prisma直参照の解消など
- アンケートやフォームのURLスキーム検証を入れてXSSを防止

## 使った技術

- Next.js / TypeScript
- PostgreSQL / Prisma
- Firebase Auth / Dify
- GCP (Cloud Run / Cloud Armor) / Terraform
