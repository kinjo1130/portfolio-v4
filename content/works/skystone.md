採用プラットフォーム「youlish」の開発に参加しています。AI面接機能を中核に、フロントエンドからインフラまで横断的に担当し、リポジトリの最多コントリビューターです。

## やったこと

- **AI面接機能**
  - 面接結果の外部共有リンク、TTS（音声合成）、文字起こし精度の改善（質問文脈の利用・音声前処理）
  - 規約同意モーダル、面接完了通知メール、面接官画像アップロード
- **求職者・企業向け機能**
  - Googleログイン、非同期面接後アンケート、求人票フィルタ、住所からの都道府県抽出による地域ミスマッチ抑制
  - 企業向け課金プラン機能と管理画面の利用枠設定UI
- **インフラ・計測**
  - Terraformでの本番環境管理（drift解消、Secret Manager、レイテンシアラート調整）
  - アフィリエイト成果通知、GTM導入
- **コード品質・セキュリティ**
  - コード規約（backend / frontend / infra）の導入とESLintでの規約検知強化
  - 型エラー解消とCI型チェックの復帰、URLスキーム検証によるXSS防止

## 使った技術

- Next.js / TypeScript
- PostgreSQL / Prisma
- Firebase Auth
- GCP (Cloud Run / Cloud Armor) / Terraform
