AIマーケティング分析・クリエイティブ提案プラットフォーム「GrowthMan」の開発を中心に参加しています。あわせて、Claude Codeを使った自動PRレビューや社内スキル共有など、開発基盤の整備も担当しています。

## やったこと

- **GrowthMan（AIマーケ分析・クリエイティブ提案）**
  - クリエイティブ制作機能: バナー生成・複数画像生成、ヒアリングUI（選択式・自由入力）、Remotionによる動画生成
  - プラン制御、招待まわりの修正、通貨入力などのUX改善
  - Google広告のOAuth審査対応（Search Console所有権確認、プライバシーポリシー整備）
- **開発基盤**
  - Claude Codeによる自動PRレビュー環境の構築（レビューworkflow、メンション起動）
  - 社内向けClaude Codeスキル・設定集の整備、SupabaseとVercelのTerraform管理

## 使った技術

- Next.js / TypeScript / React
- PostgreSQL / Prisma
- OpenAI API / Google Ads API / Meta API
- Remotion / Terraform
