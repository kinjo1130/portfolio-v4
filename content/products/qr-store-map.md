## 売り場の場所をQRで引けるようにするサービス

店内で「あの商品どこ？」となったとき、掲示されたQRコードを読むだけで売り場マップと商品カテゴリの位置を確認できるWebサービスです。店舗側は管理画面でマップとカテゴリを登録し、掲示用のQRコードを生成できます。

### 技術

- Next.js (App Router) / React / Tailwind CSS
- Hono / PostgreSQL / Prisma / Better Auth
- pnpm workspace の monorepo 構成

2026年5月に作ったMVPです。
